(minimap2-software-setup)=
Minimap2 and samtools run inside an Apptainer container in this tutorial. If you copied the prebuilt `minimap2_08OCT2025_v1.sif` image into `/staging/<netid>/genomics_tutorial/software/` during [Tutorial Setup](./03.2-Tutorial-Setup.md), your software environment is ready and you can continue to [Index the Reference Genome](./03.4-Index-Reference.md). Read on if you want to build the image yourself, or if you need a different version of Minimap2.

If you are not already logged into a CHTC Access Point (AP), do so now via SSH:

```bash
ssh <netid>@ap2001.chtc.wisc.edu
cd ~/genomics_tutorial/
```

:::{seealso} Never Built an Apptainer Container Before?
If you have never built an Apptainer container before, refer to the [Apptainer Container Building Guide](https://chtc.cs.wisc.edu/uw-research-computing/apptainer-htc) for more information on building Apptainer containers on CHTC.
:::

## Review the Minimap2 Definition File

1. The repository ships the container recipe as `software/minimap2.def`. It starts from a Miniconda base image and installs Minimap2, samtools, and bedtools from the bioconda and conda-forge channels:

   ```{code} bash
   :filename: software/minimap2.def
   :linenos:
   Bootstrap: docker
   From: continuumio/miniconda3:latest

   %post
       conda install -c bioconda -c conda-forge minimap2 samtools bedtools -y
   ```

   :::{tip} Pin your versions
   `miniconda3:latest` and an unpinned `conda install` give you whatever is current on the day you build. That is convenient for a tutorial and bad for reproducibility. When you adapt this recipe, pin the base image tag and the package versions, for example `minimap2=2.30 samtools=1.22.1`.
   :::

## Build Your Minimap2 Apptainer Container Interactively

### Write Your `minimap2_build.sub` Submit File

2. Create a submit file for an interactive build job. Open a text editor, such as `vim` or `nano`, and save the following as `software/minimap2_build.sub`:

   ```{code} bash
   :filename: software/minimap2_build.sub
   :linenos:
   :emphasize-lines: 3,9
   log = build.log

   transfer_input_files = software/minimap2.def

   +IsBuildJob = True

   request_cpus = 4
   request_memory = 16GB
   request_disk = 16GB

   queue
   ```

   :::{caution} Never build containers on the Access Point or in a standard job
   Building a container needs permissions and resources that only the dedicated build nodes provide, which is what `+IsBuildJob = True` requests. A standard job will fail, and building on the Access Point slows the machine down for every other user and violates CHTC's usage policies.
   :::

3. Submit the build job as an interactive job:

   ```bash
   condor_submit -i software/minimap2_build.sub
   ```

   HTCondor waits for a build node, then drops you into a shell on it. Your prompt changes from `ap2001` to a `build` hostname, and `minimap2.def` is waiting in the job's scratch directory.

### Build Your Minimap2 Apptainer Container

4. Build the image. Include the software name, build date, and a version number in the file name:

   ```bash
   apptainer build minimap2_15OCT2026_v1.sif minimap2.def
   ```

   The build downloads the base image and the conda packages and takes several minutes.

   :::{attention} Unique names matter for OSDF
   This tutorial transfers the container with an `osdf:///` URL, and OSDF caches files by name. If you rebuild the image and keep the old file name, jobs may receive the cached old image, go on hold repeatedly, or produce results from the wrong software version. Change the date or the version number every time you rebuild.
   :::

## Move Your Container to Your `/staging` Directory

5. Move the finished image to the `software/` directory in your `/staging` tutorial directory:

   ```bash
   mv minimap2_15OCT2026_v1.sif /staging/<netid>/genomics_tutorial/software/
   ```

6. Exit the interactive build job to return to the Access Point:

   ```bash
   exit
   ```

7. If your image has a different name than `minimap2_08OCT2025_v1.sif`, update the `container_image` line in `minimap2_index.sub` and `minimap2_mapping.sub` to match.

:::{note} The Sniffles2 recipe
`software/sniffles2.def` builds a container for [Sniffles2](https://github.com/fritzsedlazeck/Sniffles), a structural-variant caller that takes the sorted BAM files this tutorial produces as input. It is not used in this tutorial; see [Next Steps](./03.7-Next-Steps.md).
:::
