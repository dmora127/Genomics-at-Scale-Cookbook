## Before You Begin

You will need the following before moving forward with the tutorial:

1. A CHTC HTC account. If you do not have one, request access at the [CHTC Account Request Page](https://chtc.cs.wisc.edu/uw-research-computing/form.html).
2. A CHTC `/staging` directory with **at least 500 GB of free space**. If you do not have one, request it through the [CHTC large data guide](https://chtc.cs.wisc.edu/uw-research-computing/file-avail-largedata); if yours is too small, ask for more through the [quota request form](https://chtc.cs.wisc.edu/uw-research-computing/quota-request).
3. Basic familiarity with HTCondor job submission. If you are new to HTCondor, complete the CHTC [Roadmap to getting started](https://chtc.cs.wisc.edu/uw-research-computing/htc-roadmap) and read [Practice: Submit HTC Jobs using HTCondor](https://chtc.cs.wisc.edu/uw-research-computing/htcondor-job-submission).
4. Basic familiarity with the Linux command line. If you are new to the command line, consider working through the [Unix Shell](https://swcarpentry.github.io/shell-novice/) lesson from Software Carpentry.
5. Basic familiarity with genome assembly workflows. The [hifiasm documentation](https://hifiasm.readthedocs.io/) is a good reference for the tool itself.

:::{warning} Genome assembly needs a lot of disk
The reads alone are 318 GB, and the assembly job writes its outputs back to `/staging` as well. Check your `/staging` quota and usage with `quota -vs` or `du -sh /staging/<netid>` before you start; see the CHTC guide on [checking disk quota and usage](https://chtc.cs.wisc.edu/uw-research-computing/check-quota). A download that runs out of space halfway through wastes an hour.
:::

:::{hint} No need to be a genomics expert!
You do not need to be a genomics expert to follow this tutorial. The commands and scripts are beginner-friendly and self-contained while reflecting real-world research workflows.
:::

:::{note} Versions used in this tutorial
| Component | Value |
|-----------|-------|
| hifiasm | 0.25.0-r726 (the `--ont` mode used here needs 0.21 or newer) |
| Container base image | `condaforge/miniforge3:latest` as of 8 April 2026 |
| Container image | `hifiasm_08APR2026_v1.sif` (370 MB), published by CHTC at `osdf:///osg-public/containers/` |
| Reads | `SRR22085263.fastq` (318 GB, uncompressed), published by CHTC at `osdf:///osg-public/data/tutorial-CHTC-Genome-Assembly/` |
| Pelican client | the `pelican` command installed on the Access Point |

Newer hifiasm releases follow the same workflow. Do not reuse the `.bin` files that hifiasm writes with a different hifiasm version; rerun from scratch instead.
:::

## Materials

Log into a CHTC Access Point (AP):

```bash
ssh <netid>@ap2001.chtc.wisc.edu
```

Clone the companion tutorial repository, which contains the executable, submit file, and container definition used in this tutorial:

```bash
git clone https://github.com/CHTC/tutorial-CHTC-Genome-Assembly.git
cd tutorial-CHTC-Genome-Assembly/
```

Create the `logs/` directory that the submit file writes to, and the companion `/staging` directory that will hold the reads and the assembly output:

```bash
mkdir -p logs
mkdir -p /staging/<netid>/tutorial-CHTC-Genome-Assembly/Assembly_Output
```

:::{note} About the `<NetID>` placeholder
The submit file and script in the companion repository spell the NetID placeholder `<NetID>`. This cookbook writes it `<netid>`. Either way, replace it with your own NetID wherever it appears.
:::

## About the Toy Dataset

The dataset is a full Oxford Nanopore sequencing run, not a toy: the whole genome of **Tater**, a Pallas's cat (*Otocolobus manul*) living at the Utica Zoo in New York. The Pallas's cat is a small wild cat of the grasslands and montane steppes of Central Asia, and Tater was the first of the species to have its genome sequenced, by the [Faulk Lab](https://faulklab.cfans.umn.edu/) at the University of Minnesota ([news story](https://twin-cities.umn.edu/news-events/u-m-researchers-map-genome-worlds-grumpiest-cat)). The reads are in the Sequence Read Archive under accession [SRR22085263](https://www.ncbi.nlm.nih.gov/sra/SRR22085263). CHTC has published a copy on OSDF so that you can fetch it with Pelican, as described in [Stage Your Nanopore Reads](./04.4-Stage-Reads.md).

| Property             | Value                                   |
|----------------------|-----------------------------------------|
| Species              | *Otocolobus manul* (Pallas's cat)       |
| Specimen             | Tater                                   |
| Sequencing platform  | Oxford Nanopore Technologies            |
| Library preparation  | Ligation Sequencing Kit                 |
| Expected genome size | ~2.4 Gb, comparable to the domestic cat |
| SRA accession        | SRR22085263                             |
| File                 | `SRR22085263.fastq`, 318 GB uncompressed |

## Time Estimation

Plan about 1-2 hours for the tutorial walkthrough, most of it waiting for the reads to download (about an hour for 318 GB). The assembly job itself runs for 4-12 hours once it starts, and a request for 16 CPUs and 128 GB of memory can wait in the queue for several hours before a slot that large frees up. Submit it, then come back the next day.

## Recommended Directory Structure

The cloned repository has the layout below. The `logs/` directory is not in the repository; you created it above:

```bash
./tutorial-CHTC-Genome-Assembly/
├── Assembly_Output/               # empty in /home; the job writes to the /staging copy
├── Toy_Dataset/
│   └── README.md                  # notes on the dataset
├── assembly.sub                   # submit file for the assembly job
├── logs/                          # HTCondor .log, .out, and .err files
├── scripts/
│   └── assembly.sh                # executable: run hifiasm, convert GFA to FASTA, package the outputs
├── software/
│   ├── build.sub                  # interactive build job for the container (optional)
│   └── hifiasm.def                # container recipe (optional)
└── README.md                      # the tutorial, as a GitHub README
```

You also have a companion **`/staging`** directory for the reads and the assembly output:

```bash
/staging/<netid>/tutorial-CHTC-Genome-Assembly/
├── Assembly_Output/
│   └── assembly_output.tar.gz     # written by the assembly job
└── SRR22085263.fastq              # the reads, staged in Stage Your Nanopore Reads
```
