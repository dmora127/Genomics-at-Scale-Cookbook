# Before You Begin

You will need the following before moving forward with the tutorial:

1. [X] A CHTC HTC account. If you do not have one, request access at the [CHTC Account Request Page](https://chtc.cs.wisc.edu/uw-research-computing/form.html).
2. [X] Basic familiarity with HTCondor job submission. If you are new to HTCondor, complete the CHTC ["Roadmap to getting started
"](https://chtc.cs.wisc.edu/uw-research-computing/htc-roadmap/) and read the ["Practice: Submit HTC Jobs using HTCondor"](https://chtc.cs.wisc.edu/uw-research-computing/htcondor-job-submission).
3. [X] Basic familiarity with linux command-line environment. If you are new to linux command-line, consider completing the ["Introduction to Linux Command Line"](https://chtc.cs.wisc.edu/uw-research-computing/introduction-linux-command-line/) guide.
4. [X] Understand the general workflow of long-read sequencing analysis. If you are new to long-read sequencing, consider reviewing introductory materials such as the [Oxford Nanopore Technologies website](https://nanoporetech.com/) or relevant literature.
5. [X] Sufficient disk quota and file permissions in your `/home` and `/staging` directories.

:::{hint} No need to be a genomics expert!
You do not need to be a genomics expert to follow this tutorial. The commands and scripts are beginner-friendly and self-contained while reflecting real-world research workflows.
:::

## About the Toy Dataset

A sample toy dataset has been included with this repository under `inputs/`. This dataset is publically available from the [ONT Open Datasets page](https://nanoporetech.com/resource-centre/open-datasets). It includes POD5 files from _Drosophila melanogaster_ Berkley Drosophila Genome Project (BDGP) iso-1 strain using R10.4.1 Kit 14 chemistry flow cells for DNA sequencing.
You can use these files to practice basecalling with Dorado on CHTC. The dataset is small enough to complete the tutorial in a reasonable amount of time, while still being representative of real-world data. 


Toy pod5 files were generated from the deposited FAST5 files using the `pod5` tool provided by XXXXXX. Files were generated using the following command:

```bash
pod5 convert fast5 </path/to/input_FAST5s> --output </path/to/output_pod5s> --one-to-one
``` 

These examples help illustrate some of the potential use-cases of running Dorado on CHTC. 

# Time Estimation

Estimated time: plan ~1–2 hours for the tutorial walkthrough. Each basecalling job typically takes 30 minutes or more depending on dataset size and cluster load. Small test runs often complete in 10–30 minutes.

# Recommended Directory Structure

Use a layout like the one below (directories may already exist if you ran the setup script):

```bash
./tutorial-ONT-Basecalling/
├── executables                        # scripts for preprocessing and running dorado jobs
│   ├── preprocessing_pod5s.sh
│   └── run_dorado.sh
├── inputs                             # POD5 inputs
├── list_of_pod5_files.txt             # one POD5 path per line
├── logs                               # condor .log/.out/.err
│   ├── err
│   └── out
├── outputs                            # basecalled outputs (BAM/FASTQ)
├── README.md                          # Tutorial step-by-step documentation and instructions
├── run_dorado_at_CHTC.sub
├── run_dorado.sub                     # HTCondor submit file (GPU)
├── software                           # containers recipes 
│   └── dorado.def
└── tutorial-setup.sh                  # optional helper to set up the tree
```

You also have a companion **`/staging`** directory for storing large files, such as containers and Dorado models:

```bash
/staging/<netid>/tutorial-ONT-Basecalling/
├── data/
│   ├── dna_r10.4.1_e8.2_400bps_fast@v4.2.0_5mCG_5hmCG@v2.tar.gz
│   ├── dna_r10.4.1_e8.2_400bps_fast@v4.2.0.tar.gz
│   ├── rna004_130bps_sup@v5.2.0.tar.gz
├── software/
│   └── dorado_build1.2.0_27OCT2025_v1.sif
```

Run the included `tutorial-setup.sh` script in the companion repository to create this structure.
