This section covers a key preparatory step before submitting your basecalling jobs to CHTC: splitting your POD5 files by sequencing channel.


# Split Your Reads for Basecalling
When basecalling our sequencing data on Dorado we can subdivide our POD5 files into smaller individual subsets. This subdivision of our files enables us to take advantage of the OSPool's High Throughput Computing (HTC) principles, significantly decreasing the time-to-results for our basecalling. We will use the `POD5` package installed in our `dorado.sif` container—if you need to generate the `dorado.sif` Apptainer image, refer to [Setting up our software environment](#set-up-your-software-environment). 

1. Move to your `inputs/` directory where your POD5 files are located:
    ```bash
    cd ~/tutorial-ONT-Basecalling/inputs/
   ```

2. Launch an interactive Apptainer shell session on the Access Point (AP) using your `dorado_build1.2.0_27OCT2025_v1.sif` container:
    ```bash
    apptainer shell --bind "$PWD" /staging/<netid>/tutorial-ONT-Basecalling/software/dorado_build1.2.0_27OCT2025_v1.sif
   ```
   
3. Create a table mapping each read ID to its channel:
    ```bash
    pod5 view <pod5_dir> --include "read_id, channel" --output summary.tsv
   ```
   _This will generate a TSV table mapping each read_id to each channel for basecalling. You can replace `<pod5_dir>` with `./`, if you're in the current directory with your POD5 files._

4. Subset your POD5 reads by channel using the `summary.tsv` table created in the previous step. Output the POD5 subsets to `split_pod5_subsets/`:
    ```bash
   pod5 subset <pod5_dir> --summary summary.tsv --columns channel --output split_pod5_subsets
   ```
   
   Your `--output` path `split_pod5_subsets/` should point to a path in your `/home` directory on the AP, **not** your `/staging` directory. After this command completes, the `split_pod5_subsets/` directory should contain ~512 subsetted POD5 each corresponding to a different sequencing channel on the flowcell.

   :::{warning} This step **will** take a while - Only run this on the AP's `/home` directory!
   **This step will take a while depending on the size of your POD5 files and the number of channels present in your data.** It will generate one pod5 file per channel in the `split_pod5_subsets` output directory. Most MinION Flow Cells have 512 channels, so you should expect to see ~512 POD5 files in your output directory. **Never output your subsetted POD5 files to your OSPool directory, as it will cause excessive strain on shared storage resources and violate OSPool usage policies.** Only output your subsetted POD5 files to your home directory.

   This process will create ~512 smaller POD5 files in the `split_pod5_subsets/` directory, each corresponding to a different sequencing channel. These smaller files will be used for parallel basecalling jobs on CHTC. It is **important to only run this step on the Access Point (AP)'s `/home` directory** to avoid overloading shared storage resources. `/staging` is not suitable for this operation and can cause serious performance issues. Failure to comply with this guideline may result in suspension of your CHTC account.
   :::

5. Exit the Apptainer shell:
    ```bash
   exit
   ```
   _You may have to run `exit` multiple times to exit the Apptainer shell and return to your normal bash shell._
   
6. Create a list of POD5 files to iterate through during job submission:

    ```bash
    ls split_pod5_subsets > ~/tutorial-ONT-Basecalling/list_of_pod5_files.txt
   ```
   
    If you `head` this new file you should see an output similar to this:

    ```
    [user.name@ap40 user.name]$ head ~/tutorial-ONT-Basecalling/list_of_pod5_files.txt
    channel-100.pod5
    channel-101.pod5
    channel-102.pod5
    channel-103.pod5
    channel-104.pod5
    channel-105.pod5
    channel-106.pod5
    channel-107.pod5
    channel-108.pod5
    channel-109.pod5
    [user.name@ap40 user.name]$ 
   ```
